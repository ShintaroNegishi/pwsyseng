# モデルの仮定と限界

教材として単純さを優先した結果、意図的に落としている効果があります。
授業で「なぜそう置いたのか」を説明できるよう、ここに整理しておきます。
前半が運用・計画パート（`gridops`）、後半が安定度パート（`genstab`）です。

## 運用・計画パート（gridops）

### データに関する単純化

同梱ケース `wscc9.yaml` は、Anderson & Fouad の WSCC 3 機 9 母線系統を
**教材用に拡張したもの**です。原典にない値を著者が設定しています。

| 仮定 | 影響 |
|---|---|
| 線路の熱容量 `rate_a` / `rate_b` は原典になく、**交流の N-1 潮流から逆算した自作の値** | N-1 でちょうど 2 本（5-7 と 7-8）が拘束するよう意図的に調整しています。`rate_b` に対する N-1 の最大負荷率は 5-7 が 112.4%、7-8 が 112.5% で、**拘束しない枝の最大は 4-5 の 91.1%** です。この 91.1% と 112% の間の空きが「拘束する枝はどれか」を一意にしています。実系統の値ではありません。値を変えると第 09 回の物語が変わるので、`tools/design_ratings.py` で再設計してください |
| 発電機を 3 台から 7 号機に分解した | 起動停止の意思決定を意味のあるものにし、アデカシーの状態数を確保するためです。慣性定数の合計と過渡リアクタンスの並列合成は原典の 3 機に厳密に戻ります（`tests/test_interop.py` で確認）。**制動係数 $D$ も $H$ と同じく加算します**（`gridops.interop.aggregate_plants`）。こうしないと $D/(2H)$ が変わり、号機に分けただけで減衰比が号機数分の 1 に薄まります。同梱ケースは全号機 $d = 2.0$ なので、集約後は G1 が 6.0、G2 と G3 が 4.0 です。genstab 側の `cases/wscc9.yaml`（$d = 0$）と数値を比べるときは `to_genstab(..., damping=0.0)` を指定してください |
| **制動係数を原典の $D = 0$ から $D = 2.0$ に変えた** | 数値上の理由です。$D = 0$ では固有値が虚軸上に乗り、運転点をわずかに動かすだけで `genstab.eac` の定態不安定警告が出たり出なかったりします。経済負荷配分・起動停止計画で運転点を動かしてから安定度に渡すのが本教材の中心の流れなので、この揺れは授業の妨げになります。実機の同期機は制動を持つので物理的にも正当な設定ですが、**教科書の CCT と比べるときはこの差を踏まえてください** |
| 燃料費・起動費・最低運転停止時間・強制停止率はすべて自作 | オーダーは日本の電源構成に寄せていますが、実プラントの値ではありません。同一発電所内の号機で燃料費をわずかにずらしてあるのは、混合整数計画の解が縮退して入切表がソルバの版で変わるのを避けるためで、物理的な意味はありません |
| 24 時間の需要形状・太陽光出力・年間 8760 時間の需要は合成データ | 第三者の実需要データを再配布しない方針の帰結です。seed を固定しているので誰でも同じ系列を作れます。実需要の相関構造（気温・曜日・突発事象）は再現していません |

### 潮流計算の単純化

| 仮定 | 影響 |
|---|---|
| 三相平衡・正相のみ | 不平衡故障は対象外です。genstab が扱う三相地絡と整合します |
| PV 母線の無効電力制限による PV→PQ 切替は反復の外で再判定し、**PV→PQ の一方向にしか切り替えない** | 厳密には $\|V\|$ が設定値まで戻せる母線を PQ→PV に戻す必要があります。両方向にすると切替が振動して収束しないことがあるため、一方向に割り切っています。**外側の周回は必ず止まりますが、得られる解は厳密ではありません**（`solve(..., enforce_q_limits=True)` の Notes に同じことを書いてあります） |
| Newton 法の修正量は $[\Delta\theta; \Delta\|V\|/\|V\|]$ で取る | ヤコビアンの $N$, $L$ ブロックに $\|V\|$ を掛けた形（$\partial P/\partial\|V\| \cdot \|V\|$）に対応します。教科書によっては $\Delta\|V\|$ をそのまま未知数に取るので、**ヤコビアンの数値を文献と比べるときは規約を確認してください** |
| Fast Decoupled は **XB 版**（Stott & Alsac の原型） | $B'$ は抵抗・充電容量・タップ・位相調整角を落とした $1/x$ だけの行列、$B''$ は実際の Ybus の虚部（位相調整角のみ落とす）です。BX 版は抵抗を落とす側が逆で、$r/x$ の大きい配電系統ではそちらのほうが収束します。**「Fast Decoupled は収束が遅い」という観察は、版の選択の話であることがあります** |
| ヤコビアンは解析式で書く | genstab が数値線形化を採るのと方針が違います。潮流方程式は固定でモデルが差し替わらないので解析式が書けるためで、正しさは中心差分と突き合わせて確認しています |
| 継続法はノーズ点を挟み撃ちするところまで | Q-V 曲線・無効電力余裕・調相設備の最適配置は演習での言及に留めています |
| 変圧器のタップは固定 | タップ調整による電圧制御は扱いません。WSCC 9 母線の変圧器はすべて公称タップなので、このケースでは無害です |

### 直流近似の単純化

| 仮定 | 影響 |
|---|---|
| $\|V\|=1$、$r=0$、$\sin\theta\approx\theta$、充電容量を無視 | 無効電力と電圧の情報が完全に失われます。**交流の枝潮流 $\|S\|$ は直流の $P$ と最大 47.6% 違います**（枝 4-5 で 0.5614 対 0.3803）。熱容量の判定を直流で行ってはいけません |
| 損失を無視する | 交流で線路損失として消える分（基準ケースで 0.046410 p.u.、約 1.5%）がすべてスラック母線に乗ります。**このずれが送電損失であり、経済負荷配分の回の題材そのものです** |
| 位相調整変圧器の定数項を無視 | 同梱ケースには位相調整変圧器がないので影響しません。自分でケースを作るときは注意してください |
| N-1 は線路の 1 回線開放のみ | 発電機事故・変圧器事故・多重事故（N-2）は扱いません。発電機事故は LODF では扱えず、注入の再配分が必要です。**「N-1 の一部しか見ていない」ことをセキュリティの回で明示します** |
| **LODF によるスクリーニングは熱容量しか見ない** | これは欠陥ですが、隠さずに主教材にしています。WSCC 9 母線で枝 4-6 を開放すると、熱容量は最悪でも 75.7% で健全なのに、母線 6 の電圧が 0.9418 p.u. まで落ちて下限 0.95 を割ります。熱容量だけを見るスクリーニングはこの事故を「健全」と誤判定します。`screen_n1(check_voltage=True)` は候補に交流潮流を解き直す 2 段構えにしています |

### 経済負荷配分・起動停止計画の単純化

| 仮定 | 影響 |
|---|---|
| 経済負荷配分は 2 次費用、直流最適潮流と起動停止計画は 1 次または区分線形 | PuLP が扱えるのが線形計画と混合整数線形計画だけだからです。**区分線形の目的値は厳密な費用を必ず過大評価します**（凸性から割線が曲線の上側に来る）。真の費用は入切を固定して等 λ 法で解き直します |
| 起動費は単一（熱間／冷間の区別なし） | 停止時間に応じた段階的起動費には追加の 0-1 変数か区分定式化が必要です。教材では割り切っています |
| 運転予備力は「同期並列した未負荷容量」$\sum(P_{max}u - p) \ge R$ | 「起動していれば即座に全出力が出せる」という仮定を含みます。瞬動予備力はランプ律速で別に扱います |
| 実行不可能は緩和変数（`shed` / `spill`）で回避する | 例外で落ちる代わりに「12 時に 80 MW 足りない」という形で返します。授業を止めないためですが、緩和変数が立っている解は最適解ではないので、`cost_breakdown["penalty"]` を必ず確認してください |
| 混合整数計画の解は縮退する | 同一費用の別解が多数存在します。**答え合わせは入切表ではなく総費用で行ってください。** 対称性除去制約を用意していますが、完全には防げません |
| 交流最適潮流 (ACOPF) は扱わない | 非凸性・局所解・初期値依存という重要な論点を落としています。直流近似が何を捨てているかは交流との誤差として定量化しますが、「直流最適潮流の解が交流で実行可能とは限らない」という核心には触れません |

### アデカシーの単純化

| 仮定 | 影響 |
|---|---|
| 発電機は 2 状態モデル（全出力／全停止） | 部分停止 (derated state) は扱いません |
| モンテカルロは非逐次法（状態サンプリング）のみ | **発生頻度 LOLF と平均継続時間が出せません。** `Unit` は `mttf` / `mttr` のフィールドを持たせてあるので逐次法は発展課題として実装できます。強制停止率 0.05 が「年 1 回 438 時間」でも「年 50 回 8.8 時間」でも成り立つという運用上決定的な区別は、発展課題に回しています |
| 供給支障は「利用可能容量 < 負荷」（等号を含めない） | 離散容量では等号が実際に起こります。規約を固定してテストで守っていますが、文献値と比べるときは相手の規約を確認してください |
| 計画停止（補修）は扱わない | 強制停止のみです。実務の設備計画では計画停止スケジュールが LOLE に大きく効きます |
| 需要の不確実性は扱わない | 需要予測誤差が 2〜3% でも LOLE が倍近く変わります。発展課題として離散化の手順のみ示します |
| 送電制約を考慮しない | 発電設備の十分性だけを見ています。実際には送電制約で「あるのに送れない」ことが起こります。セキュリティの回と合わせて理解してください |

### 系統規模に関する単純化

| 仮定 | 影響 |
|---|---|
| WSCC 9 母線 1 系統で通す | 学生が系統を覚え直さずに済むことを優先しました。**コードが特定の系統に依存していないことの検証**は、小さなケースと発展課題（IEEE 14 母線を MATPOWER から自分で YAML に起こす）に委ねています |
| 密行列で解く | 教材規模（9 母線）では十分です。実系統規模での疎行列の必要性、母線数に対する反復回数の増え方は体験できません |
| 起動停止計画は 7 号機 × 24 時間 | PuLP + CBC で 0.5 秒程度です。数百機・週単位の問題は扱えません |

## 安定度パート（genstab）

### 発電機モデル

### 古典モデル（`ClassicalMachine`, 2 次）

| 仮定 | 影響 |
|---|---|
| 内部起電力 $E'$ が一定 | 界磁磁束の変化を無視するため、**AVR の効果を表現できない**。励磁制御を扱うには 1 軸モデル以上が必要。 |
| 制動を線形項 $D\Delta\omega$ で代表 | 制動巻線の詳細な物理を集約している。$D$ は同定すべき等価パラメータであり、物理定数ではない。 |
| 突極性なし | 磁気トルクの寄与を落としている。円筒形回転子機では良い近似。 |

第 1 波の動揺（first swing）を見るには十分で、等面積法とも整合します。

### 1 軸モデル（`OneAxisMachine`, 3 次）

| 仮定 | 影響 |
|---|---|
| $x_q = x'_d$（突極性を無視） | 発電機を「$E'_q\angle\delta$ の背後に $x'_d$」という古典モデルと同じ等価回路で表せるので、ネットワーク側の計算を共通化できる。突極機（水力）では磁気トルクを落とすことになる。 |
| q 軸の過渡現象を無視 | $E'_d$ の状態を持たない。制動巻線の効果は $D$ に集約される。 |
| 磁気飽和なし | 界磁電圧と内部起電力の関係を線形としている。実機では飽和により大電流域でゲインが下がる。 |

AVR の負制動という定性的な現象は、この単純化のもとでも正しく再現されます
（`tests/test_onaxis_avr.py` で確認）。

### ネットワーク

### SMIB（`SMIBNetwork`）

事故を **転送リアクタンスの 3 段階変化**（事故前・事故中・事故後）で表しています。
教科書で最も広く使われる表現です。

**このモデルが正しく表せるのは電気出力 $P_e$ だけです。**

どのステージでも、内部起電力から無限大母線までが 1 本のリアクタンスで
つながっているとみなしています。しかし実際の地絡では事故点に分路
（地絡電流の経路）ができ、自己アドミタンスと相互アドミタンスが独立に
変わります。1 本の転送リアクタンスではこの分路成分を表せないため、
**事故中の端子電圧 $V_t$ と d-q 電流 $I_d, I_q$ は物理的に正しくありません。**

| 設定 | 電気出力 | 端子電圧 |
|---|---|---|
| `x_fault = inf` | 0（正しい） | 内部起電力に等しい（実際は 0 に落ちる） |
| `x_fault` に有限値 | 減少（近似として妥当） | **むしろ上がることがある**（ある設定で 1.055 → 1.097） |

動揺方程式は $P_e$ にしか依存しないので、**過渡安定性を論じるうえでは
この近似で十分**です。一方、事故中の端子電圧に依存する量、たとえば
AVR が事故中にどう応答するかは、このモデルの適用範囲外です。

定量的に扱うには、端子母線を残した Ybus を解くか、事故点の分路
インピーダンスを陽に持つモデルが必要になります。本パッケージは
教材としての簡潔さを優先してこれを実装していません。

### 多機系統（`MultiMachineNetwork`）

| 仮定 | 影響 |
|---|---|
| 負荷を定インピーダンスに変換 | 負荷母線を Kron 縮約で消すために必要。実際の負荷は電圧・周波数に依存するため、電圧が大きく下がる事故中は誤差が大きい。 |
| 全機が古典モデル | 励磁制御を含められない。機器間動揺の観察には十分だが、制御器の効果は SMIB で扱う。 |
| 潮流解を外部から与える | 潮流計算は本パッケージの対象外。ケースファイルに数値として同梱し、整合性はテストで検算している。 |

### 数値解法

### 積分区間の分割

事故の発生・除去でネットワークが不連続に変わります。`simulate` はこの切替時刻で
積分区間を分割し、区間ごとにネットワーク状態を固定して積分します。

**1 回の `solve_ivp` で不連続点をまたぐとステップ幅制御が破綻し、
教科書どおりの CCT が得られません。** 教材コードとして、ここは
省略できない部分です。

### 線形化

状態行列は中心差分（既定の刻み幅 $10^{-6}$）で求めています。解析的な線形化
（Heffron-Phillips の $K_1$〜$K_6$ など）と比べると桁落ちの分だけ精度は劣りますが、
モデルや制御器を追加してもコードを変えずに済む利点があります。
解析式と一致することは `tests/test_smallsignal.py` で確認しています。

### 安定判定

| 系 | 判定基準 |
|---|---|
| SMIB | 位相角偏差がしきい値（既定は事故後の不安定平衡点 $\delta_u$ まで）を超えないか |
| 多機系統 | 機器間の角度差 $\max_{i,j}\|\delta_i - \delta_j\|$ がしきい値を超えないか |
| 孤立系 | 状態が有界か |

いずれも工学的な便宜上の判定であり、厳密な安定判別ではありません。
制動が非常に弱い場合、大きく振れてから戻る（安定だが判定は不安定になる）
ことがあるため、波形も目視で確認してください。

### 単位系

Kundur 流の標準形を採用しています。

$$
\frac{d\delta}{dt} = \omega_s \Delta\omega, \qquad
2H \frac{d\Delta\omega}{dt} = P_m - P_e - D\,\Delta\omega
$$

速度偏差 $\Delta\omega$ を p.u. で持つのが要点で、慣性定数 $H$ [s] と
制動係数 $D$ [p.u.] がそのまま教科書の値として使えます。

簡略形 $d\delta/dt = \omega$（速度偏差を rad/s で持つ形）とは係数の置き方が
違うだけで等価です。既存の研究室コード `GeneratorControl/simulation.py` は
後者で書かれており、$M = 2H$、$\omega_s = 1$ と対応づけると厳密に一致します
（`tests/test_classical.py` で確認）。
