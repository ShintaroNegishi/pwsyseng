# データの出典と再配布の方針

同梱するデータは「公知の標準ベンチマーク」と「著者が作った合成データ」に
限っています。第三者が編纂した研究用データは同梱せず、取得手順だけを示します。

| データ | 扱い | 根拠 |
|---|---|---|
| WSCC 3 機 9 母線系統の系統定数（母線・線路・変圧器・負荷・慣性定数・過渡リアクタンス） | **同梱する** | 過渡安定度の標準ベンチマークとして広く公開されている数値パラメータの表です。ファイル冒頭と本書に出典を明記しています。安定度パート（genstab）の単体公開時に同じ前例があります |
| 母線種別・設定電圧 | **同梱する（自作）** | 原典の潮流解と整合するよう著者が決めた値です |
| 線路の熱容量 `rate_a` / `rate_b` | **同梱する（自作）** | 原典にありません。交流の N-1 潮流から著者が逆算しました。設計根拠は `docs/model_assumptions.md` と `tools/design_ratings.py` にあります |
| 号機分解の諸元（容量・燃料費・起動費・最低運転停止時間・強制停止率） | **同梱する（自作）** | 原典にありません。オーダーは日本の電源構成に寄せていますが、実プラントの値ではありません |
| 24 時間の需要形状・太陽光出力プロファイル | **同梱する（合成）** | 正規化した係数のみで、実データではありません |
| 年間 8760 時間の需要 | **同梱する（生成パラメータのみ）** | seed を固定した生成関数で作ります。系列そのものはファイルに入れていません |
| 東京電力パワーグリッドのエリア需給実績 | **同梱しない** | 第三者の公開データです。発展課題として取得手順のみ `docs/references.md` に記します |
| JEPX スポット価格 | **同梱しない** | 利用規約があります。取得手順のみ記します |
| 研究室の `PWSYS` にある日本 10 エリアのユニットデータ | **同梱しない** | 実在の発電所名を含む第三者編纂データです |
| IEEE 14 / 30 / 118 母線系統 | **同梱しない（発展課題）** | 研究室の `OPF/` にファイルがありますが出所が明確でありません。使う場合は MATPOWER（BSD-3-Clause）から起こし直し、ライセンスを明記する手順を発展課題として提示します |

## 原典

> P. M. Anderson and A. A. Fouad, *Power System Control and Stability*,
> 2nd ed., IEEE Press, 2003, Chapter 2.

## 新しいデータを足すときの手順

1. 出典（書誌または URL と取得日）をケースファイルの冒頭コメントに書く
2. 原典にない値を足したら、**どれが自作かをコメントで区別する**
3. 第三者が編纂したデータは同梱せず、取得スクリプトだけを置く
4. 本書の表に 1 行足す
5. 公開前チェックリスト（`docs/publishing_checklist.md`）で確認する
